英雄篇:找到你的本命

29 位英雄,四大职业。先搞懂每个职业是干什么的,再挑一位新手友好的开始练。

四大职业,一分钟看懂

决斗者

冲在最前面

负责"进点开路":用闪光、位移技能撕开防线,第一个进点、第一个交火。枪法成长最快的职业。

控场者

用烟幕画地图

负责放烟、封路、遮视野,把敌人逼进你想要的位置。团队里最"战术"的职位,被称为烟男烟女。

先锋者

侦察与开团

负责拿信息:侦察箭、无人机、闪光。让队友知道"敌人在哪、有几个",进攻从"知道"开始。

哨卫者

守家与兜底

负责守点布防、盯后路、治疗复活队友。防守端的定海神针,团队最可靠的靠山。

新手选人建议:第一周在 贤者(Sage)、布雷姆(Brimstone)、奇乐(Killjoy)、凤凰(Phoenix) 里挑一位固定练——这四位技能直观、容错高,能让你专心学枪法而非技能。等你对游戏有感觉了,再扩展职业池。

决斗者(8 位)— 冲在最前面

技能围绕"位移 + 闪光 + 爆发",职责是打开进攻局面。新手想练枪法,从这一排开始。

决斗者

凤凰 Phoenix

★★★★★
  • Q 闪光弹
  • C 燃烧弹
  • E 火墙
  • X 标记重生(原地复活)

新手首选!技能简单直白,大招死了还能重来一次,犯错成本最低。

决斗者

捷风 Jett

★★★★
  • Q 上升气流(跳高)
  • C 烟雾球
  • E 冲刺
  • X 飞刀

高手上限高。位移吃操作,新手容易"冲出去白给",建议有基础后再练。

决斗者

芮娜 Reyna

★★★★★
  • Q 致盲之眼
  • C 击杀回血
  • E 击杀后无敌撤离
  • X 全面强化

纯枪法英雄。技能全部围绕击杀生效,枪准就无敌,新手练枪的绝配。

决斗者

雷兹 Raze

★★★★
  • Q 颜料弹(集束爆炸)
  • C 爆破包(火箭跳)
  • E 爆炸机器人
  • X 火箭筒

爆炸开道的快乐英雄。注意技能会误伤队友,炸之前先看路。

决斗者

夜露 Yoru

★★

  • C 假身
  • E 传送门
  • X 维度漂移(隐身)

难度最高的一档。玩法依赖对地图和对手心理的理解,新手先别碰。

决斗者

霓虹 Neon

★★★
  • Q 电击弹
  • C 电网墙
  • E 高速冲刺(能量条)
  • X 激光超频

全游戏跑得最快,风一样的女子。能量管理有门槛,玩熟之前枪法先放一放。

决斗者

伊索 Iso

★★★★
  • Q 减速波
  • C 移动能量墙
  • E 契约(击杀刷新护盾)
  • X 单挑领域(强制一对一)

单挑机器,大招把敌人拖进"你的局"。枪法自信就选他。

决斗者

Waylay

★★★
  • Q 光速(两次冲刺)
  • C 饱和(减速敌人)
  • E 折射(瞬移回标记点,期间无敌)
  • X 聚合路径(光束减速敌人)

2025 年加入的光速决斗者,既能冲又能"撤回重打",进点思路非常新。

控场者(7 位)— 用烟幕画地图

烟幕是进攻的幕布、防守的遮罩。控场者往往是一个团队节奏的"指挥位"。

控场者

布雷姆 Brimstone

★★★★★
  • Q 加速信号(团队增益)
  • C 燃烧弹
  • E 天降烟幕(3 发地图圈烟)
  • X 轨道打击(地图轰炸)

新手第一烟男。放烟像画图一样直观,大招简单粗暴,先把"烟该怎么放"学明白。

控场者

蝰蛇 Viper

★★★★
  • Q 毒雾(可开关)
  • C 毒池
  • E 毒墙(可开关)
  • X 毒幕领域

毒阵一开,整片区域都是她的地盘。能量管理是难点,新手先玩布雷姆再过渡。

控场者

欧门 Omen

★★★★
  • Q 恐慌闪光
  • C 暗影瞬移
  • E 黑暗烟幕
  • X 全图传送

烟+闪+传送的万能型。能打出各种骚操作,新手可以练,但别贪图秀操作。

控场者

星癸 Astra

★★
  • Q 星云(烟)
  • C 星爆(震荡)
  • E 引力井
  • X 天界之墙(全图横墙)

星星要在地图上预放置、再用小地图遥控,同时要打枪——多线操作,新手请留到进阶。

控场者

海神 Harbor

★★★
  • Q 水波(推进开路)
  • C 水墙(可转向)
  • E 潮汐幕(横向水墙)
  • X 复仇漩涡(击退敌人)

水墙可以"边放边跟着走",进攻推进感很强,新手也能玩得明白。

控场者

克洛弗 Clove

★★★★
  • Q 减速球
  • C 烟幕
  • E 击杀回血
  • X 阵亡后原地复活

阵亡后还能继续放烟!对新手非常宽容——就算你先倒了,烟幕也照常覆盖战场。

控场者

Miks

★★★★
  • Q 共鸣(给队友加速增益)
  • C 音波弹(震荡或治疗)
  • E 波形(音波烟幕)
  • X 低音地震(锥形推退+致聋)

2026 年 3 月加入的克罗地亚控场,是唯一会治疗的控场者,进可攻退可守。

先锋者(7 位)— 侦察与开团

"打仗打的是情报"。先锋者负责把"不知道"变成"知道",是团队的眼睛和拳头。

先锋者

苏法 Sova

  • C 震荡箭
  • E 猫头鹰无人机
  • X 猎手之怒(穿墙三箭)

侦察之王。一根箭让敌人无处可藏,大招穿墙击杀爽感拉满,新手练"看地图"就从苏法开始。

先锋者

布雷克 Breach

★★★
  • Q 闪光(穿墙)
  • C 余震(穿墙爆破)
  • E 断层线(穿墙震荡)
  • X 地裂轰鸣(全场震荡)

技能全部穿墙!最不吃视野的先锋,配合队友进点非常强。

先锋者

斯凯 Skye

★★★★
  • Q 治疗(范围回血)
  • C 探路猛虎
  • E 闪光鸟(可转向)
  • X 追猎者(追踪敌人)

又能探路又能奶人,进攻防守通吃。大招追猎者让残局敌人心发慌。

先锋者

KAY/O

★★★★
  • Q 闪光
  • C 碎片手雷

  • X 全区域压制(禁用技能)

反技能机器,专治花里胡哨。大招一开,敌人只能跟你拼枪——这正是你想要的。

先锋者

菲德 Fade

★★★

技能很凶,大招一开对面集体标记。连招稍多,新手可以先记"大招探全场"这一个用法。

先锋者

盖可 Gekko

★★★★★
  • Q 眩晕怪(甩头眩晕)

  • X 抓人怪(束缚)

新手友好!他的小怪物会自己帮你装包、拆包、打人——技能"自动挡",放完就能专心对枪。

先锋者

Tejo

★★★
  • Q 制导导弹(可改向)
  • C 空投震击
  • E 自动炮塔(标记敌人)
  • X 全图轰炸

2025 年初加入的哥伦比亚先锋,导弹会"拐弯",大招全图轰炸清死角,清点神器。

哨卫者(7 位)— 守家与兜底

布下天罗地网,让敌人进点寸步难行。新手在防守端最容易获得成就感的位置。

哨卫者

贤者 Sage

★★★★★
  • Q 缓速球
  • C 冰墙(封路)
  • E 治疗
  • X 复活队友

新手第一辅助。每局都能救人于水火,队友最爱的存在。先把"治疗和复活时机"练明白。

哨卫者

奇乐 Killjoy

★★★★★
  • Q 蜂群手雷
  • C 警戒机器人
  • E 炮台(自动射击)
  • X 全面封锁(禁锢全场)

新手守点首选。炮台+警报机器人自动看门,大招把进点的敌人原地禁锢,省心又强力。

哨卫者

赛弗 Cypher

★★★★
  • Q 囚笼(封视野)
  • C 绊线(眩晕敌人)
  • E 间谍摄像头
  • X 尸体扫描(显示敌人位置)

"情报特工",整张地图都是他的眼线。布置感强,玩起来像下棋。

哨卫者

尚勃勒 Chamber

★★★
  • Q 猎头手枪(自带精准手枪)
  • C 减速陷阱
  • E 传送信标
  • X 巡回演出(连发大狙)

"哨卫里的决斗者",守点还带传送。大招大狙一枪一个,但非常吃枪法和时机。

哨卫者

Deadlock

★★★★
  • Q 音波传感器(探测脚步声)
  • C 重力网(减速区域)
  • E 壁垒之幕(封路网墙)
  • X 湮灭(束缚并拖拽敌人)

科技感满满的守点者,网墙+音波探测双保险,新手拿她守点不容易漏人。

哨卫者

Vyse

★★★
  • Q 玫瑰闪光
  • C 刺墙(穿人伤敌)
  • E 荆棘藤蔓(减速束缚)
  • X 蔷薇迷宫(全场禁锢)

玫瑰与荆棘的女机关师。大招全屏禁锢观赏性极强,布防思路比较"聪明"。

哨卫者

Veto

★★★
  • Q 束缚陷阱(减速+衰竭)
  • C 传送漩涡(定点回收)
  • E 拦截器(摧毁敌方技能道具)
  • X 进化(变身强化+免疫技能)

2025 年底加入的塞内加尔哨卫,能直接拆掉敌人的技能道具,打道具流阵容有奇效。

怎么挑英雄练

新手路线:先固定练 1 位新手友好英雄(推荐 贤者/布雷姆/奇乐/凤凰),把枪法和地图理解练扎实 → 再按你喜欢的打法扩展:喜欢冲 → 决斗者;喜欢布置 → 哨卫;喜欢指挥 → 控场;喜欢情报 → 先锋。
